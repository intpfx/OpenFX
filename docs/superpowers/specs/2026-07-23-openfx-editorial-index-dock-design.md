# OpenFX Editorial Index Dock 设计

## 背景

OpenFX 首页底部已经把构建信息、Map Poster 城市背景状态和项目命令区合并为一个语义化
Dock，但当前视觉仍像传统工具栏：完整外框、毛玻璃、阴影、三栏等权分割和密集的同级文字削弱了
首页的网格、留白与编辑式气质。

本次重设计采用用户确认的 C 方案「Editorial Index」。目标不是再次拆分功能，而是在保留统一
组件和现有交互的前提下，以两条文字基线重新组织信息层级。

## 目标

- 与 OpenFX 的白色网格、黑色正文和蓝色点睛保持一致。
- 让项目计数与搜索成为视觉中心，构建与背景信息退居元数据层。
- 通过字号、字距、基线和留白建立层级，减少容器与分割线。
- 保留当前搜索、留言、详情返回、Proxy、定位和可访问性行为。
- 桌面和移动端都保持稳定高度，不因状态切换产生重排或横向滚动。
- 提供自动、浅色和暗色三种主题模式，并避免首次绘制时发生主题闪烁。

## 非目标

- 不改变首页三列项目浏览器、卡片、背景海报或详情面板设计。
- 不修改定位授权流程、Map Poster API、服务端逻辑或隐私约定。
- 不新增筛选器、图标库、动画依赖、路由，或除 `openfx-theme` 手动主题偏好之外的持久化格式。
- 不把独立的首次定位授权胶囊合并进 Editorial Dock。
- 不强制改造独立深色管理 Console、Proxy 第三方页面或项目 iframe 的内部主题。

## 视觉结构

### 外层

`HomepageFooterDock` 继续作为唯一的语义化 `<footer aria-label="首页控制栏">`。桌面端取消
完整外框、圆角、毛玻璃和阴影，使用透明背景与一条底部细线形成编辑式索引带。

Dock 不再呈现三个等权方框。内部改为两列：

1. 左侧索引区占据剩余宽度，包含上下两条文字基线。
2. 右侧主操作跨越两行，以一条短竖线和索引区分隔。

`HomepageFooterDock` 的内容接口改为 `meta`、`index` 和 `action` 三个 React-node 插槽。
呈现层把 `meta` 放入第一条基线，把 `index` 放入第二条基线，把 `action` 放入跨行区域；
不得让 `App.tsx` 重新承担网格或断点布局细节。

### 第一条基线：元信息

从左到右显示：

- `BUILD`：弱化的全大写标签。
- `local00`：短构建哈希；完整日期和时间保留为可访问文本或 `title`，不占据主视觉。
- `THEME · AUTO`：单一文字主题控件，显示当前偏好模式。
- 蓝色状态点。
- `BACKGROUND`：弱化的全大写标签。
- `绵阳市`：当前城市名，权重高于标签但低于项目索引。
- `© OSM`：指向 OpenStreetMap copyright 页的归属链接。
- 重新定位控件：视觉上使用简洁的 `↻`，提供完整中文 `aria-label`。

不再显示冗余的 `Map Poster` 文字。城市背景、OSM 归属和重新定位已经足以表达功能。

### 第二条基线：项目索引

从左到右显示：

- 蓝色、稍大的当前结果数，例如 `13`。
- 更小、更弱的总数，例如 `/ 13`。
- 搜索输入。占据索引区剩余宽度，默认文案为 `Search the OpenFX index…`。

搜索框不绘制完整边框。默认态依靠文字与基线存在，聚焦时只出现一条蓝色底线。

### 右侧主操作

`MESSAGE` 位于独立的右侧区域，跨越两条基线。它使用蓝色状态点、全大写文字和较大字距，不使用
实心按钮或胶囊。右侧区域与索引区之间只保留一条短竖线。

详情态下主操作改为 `← 返回项目卡片`；留言态改为 `SEND`；Proxy 态改为 `OPEN`。主操作宽度
需要预留最长常用文本，避免切换时 Dock 横向跳动。

## 字体层级

沿用项目现有字体，不新增 Web Font。

- 元信息标签：约 `0.48–0.52rem`，字重 650，字距约 `0.12em`，全大写。
- 元信息值：约 `0.56–0.62rem`，常规字距，次级文字色。
- 城市名：约 `0.62–0.68rem`，字重 650，正文色。
- 当前项目数：约 `0.78–0.86rem`，字重 700，OpenFX 蓝。
- 总项目数：约 `0.55–0.6rem`，次级文字色。
- 搜索文字：约 `0.68–0.74rem`，自然字距，正文色。
- 主操作：约 `0.58–0.64rem`，字重 700，字距约 `0.1em`，OpenFX 蓝。

最终数值可以在浏览器验收中小幅调整，但层级顺序不得改变。

## 明暗主题

### 模式与控件

主题偏好只允许三个值：

- `auto`：默认值，实时跟随 `prefers-color-scheme`。
- `light`：手动锁定浅色。
- `dark`：手动锁定暗色。

Editorial Dock 第一条基线提供一个单一文字按钮。桌面显示
`THEME · AUTO`、`THEME · LIGHT` 或 `THEME · DARK`；移动端空间不足时只显示
`AUTO`、`LIGHT` 或 `DARK`，但保留完整中文无障碍名称。

按钮每次点击按 `AUTO → LIGHT → DARK → AUTO` 循环。`aria-label` 同时说明当前模式和
点击后的下一模式，例如“当前主题：自动；切换为浅色”。键盘 Enter 和 Space 使用原生按钮行为，
焦点样式与 Editorial Dock 其他主控件一致。

### 偏好与首次绘制

仅手动偏好需要持久化。使用 `localStorage` 键 `openfx-theme`：

- `light` 与 `dark` 表示手动偏好。
- 切换回 `auto` 时删除该键。
- 缺失、不可访问或值无效时按 `auto` 处理。

不把主题偏好写入 URL、cookie、服务端、数据库或分析事件。

为了避免先闪白再变暗，`entry/web/index.html` 在加载主样式和 React 入口前执行一段有边界的
同步启动逻辑：

1. 安全读取 `openfx-theme`。
2. 手动值有效时使用该值。
3. 否则读取 `matchMedia("(prefers-color-scheme: dark)")`。
4. 在 `<html>` 上写入最终的 `data-theme="light"` 或 `data-theme="dark"`。
5. 暴露只读的 `window.__OPENFX_THEME_BOOTSTRAP__ = { mode, effectiveTheme }` 首屏快照。
6. 同步更新现有 `meta[name="theme-color"]`，暗色首屏不得沿用浅色浏览器栏颜色。

React 侧从该首屏快照初始化偏好和有效主题，不再次解析首屏存储值；之后由纯函数主题模块维护
合法值、循环顺序和有效主题解析。只有偏好为 `auto` 时订阅系统主题变化；切换为手动模式或组件
卸载时移除监听。每次有效主题变化都同时更新 `<html data-theme>` 和
`meta[name="theme-color"]`。

### 颜色系统

浅色主题保留现有 OpenFX 观感：白色网格、近黑正文、灰色次级文字和蓝色强调。

暗色主题使用深灰蓝而不是纯黑：

- 页面背景为低彩度深灰蓝。
- 网格只比背景略亮，不形成高对比棋盘。
- 正文为柔和灰白，次级文字降低亮度但仍满足可读性。
- OpenFX 蓝保持品牌识别，并针对深色背景调整亮度。
- 卡片、详情面板和移动 Dock 使用分层深色表面，不使用高亮玻璃描边。
- 边框、焦点环、阴影和半透明遮罩全部由主题变量提供，不在组件规则中散落浅色常量。

需要把首页和 OpenFX 详情面板正在使用的硬编码浅色整理为语义变量，例如页面背景、网格、表面、
浮层、主次文字、边框、弱阴影和地图遮罩。独立的管理 Console 已经拥有自己的深色系统，不继承
首页主题；第三方 iframe 也不做 CSS 反相。

### Map Poster 背景

暗色主题不修改 Map Poster 请求、SVG 内容或服务端主题。客户端通过主题化遮罩、亮度、对比度和
混合模式把 `japanese_ink` 道路纹理融入深灰蓝背景：

- 道路仍可辨认，但对比度低于项目卡片与正文。
- 海报底部继续渐隐到页面背景。
- 不进行简单全页反相，不产生高亮白块。
- 定位授权胶囊和 OSM 归属链接在两套主题下都保持可读与可聚焦。

### 主题切换动效

普通模式只允许背景、表面、边框和文字颜色做不超过 180ms 的短过渡。切换时不淡化项目内容、
不移动 Dock、不重新播放卡片入场动画。

`prefers-reduced-motion: reduce` 下主题立即切换，不添加颜色过渡。

### 覆盖范围

主题覆盖：

- 首页背景、品牌、项目卡片和预览侧翼。
- Editorial Dock、搜索、留言、详情返回和 Proxy 控件外壳。
- 定位授权胶囊、定位状态、OSM 归属和城市海报遮罩。
- OpenFX 自有的项目详情面板与 Map Poster 面板。

主题不强制覆盖：

- 独立深色管理 Console。
- Proxy 加载的第三方页面。
- 各项目 iframe 或下载产物的内部 UI。

## 状态行为

### 默认与搜索

上行显示构建和城市背景信息，下行显示项目计数与搜索，右侧显示 `MESSAGE`。搜索只更新计数与
卡片结果，不改变 Dock 高度或结构。

### 留言

第二条基线原位切换为返回、`MSG` 和留言输入；右侧主操作切换为 `SEND`。不得新增外层容器，
不得改变 Dock 高度。Escape 和返回按钮继续恢复搜索态及焦点。

### 项目详情

Map Poster 在内的详情面板打开后，定位控制继续由 `HomepageLocationPoster` 暂停。元信息行只
保留可用的构建信息，不渲染空背景占位。项目索引行隐藏，右侧显示 `← 返回项目卡片`。关闭后仍
恢复到原卡片按钮。

### Proxy

第二条基线原位切换为返回按钮和 URL 输入；右侧显示 `OPEN`。现有提交、Escape 和 iframe
行为保持不变。

### 定位生成、错误和授权

- 正常生成、失败、拒绝和不可用状态占据元信息行的背景位置，使用短状态文字。
- 长状态单行省略，不得挤压项目索引或右侧主操作。
- 主题控件在默认、搜索、留言、详情和 Proxy 状态中始终可用。
- 首次定位授权仍使用独立的最高层胶囊。
- 授权期间首页和 Editorial Dock 继续模糊，并设置 `inert` 与 `aria-hidden`。
- 独立实时播报区域保持在 inert Dock 之外。
- 海报背景与 OSM 归属所有权不变，每个状态仍只出现一个可访问的归属链接。

## 响应式

### 宽屏与桌面：`>900px`

- Dock 参与首页第三行网格，不使用 fixed 定位。
- 视觉高度约 52–58px。
- 元信息和项目索引各占一条紧凑基线；右侧主操作跨两行。
- 1024px 左右优先缩短或隐藏完整构建时间，其次压缩搜索宽度；城市名、计数和主操作保持可见。

### 移动端：`<=900px`

- Dock 固定在安全区上方，使用轻薄的半透明白色底色保证地图背景上的可读性。
- 暗色主题使用对应的半透明深色表面，不出现浅色闪烁或白色底块。
- 不使用大胶囊、强阴影或三等分外框；允许使用小圆角与上下细线。
- 上行承载构建和背景元信息，下行承载计数、搜索和主操作。
- 两行交互区域都保证至少 44px 触控高度。
- 在 390px 下优先保留城市名、主题当前值、当前计数、搜索和主操作；隐藏完整构建时间和非必要
  英文标签。

断点两侧都必须满足：

- 无横向滚动。
- 无文字重叠。
- 无状态切换导致的高度跳动。
- 交互元素保持明确的可见焦点。

## 动效

普通模式只允许搜索底线、文字颜色和状态点做不超过 180ms 的短过渡。Dock 本身不位移、不缩放，
状态切换不使用扫描线或持续动画。

`prefers-reduced-motion: reduce` 下移除上述过渡。

## 组件与测试

- `HomepageFooterDock.tsx` 继续负责语义外壳与 Editorial Index 布局。
- `HomepageLocationPoster.tsx` 继续负责定位、海报、归属、授权焦点和状态生命周期。
- 新建纯函数主题模块，负责模式解析、循环顺序、有效主题解析和系统主题响应；React 组件只负责
  浏览器 I/O 与状态装配。
- `App.tsx` 只提供构建、主题、状态和命令内容，不直接声明 Dock 的网格或装饰。
- 更新 `entry/web/README.md`，记录 Editorial Index 的层级和响应式规则。

测试至少覆盖：

- 单一语义化 footer 和稳定的元信息、索引、主操作顺序。
- 默认、留言、详情和 Proxy 状态不产生第二个外层 Dock。
- 桌面无完整外框、胶囊、毛玻璃或阴影。
- 桌面两条基线和跨行主操作。
- 移动端两行结构、44px 触控目标和 390px 无溢出约束。
- 定位授权仍独立于 Dock，并保持 inert、实时播报和唯一 OSM 归属。
- 搜索、计数、焦点恢复、Escape 和主操作行为不回归。
- `auto`、`light`、`dark` 解析与循环顺序。
- 无效或不可访问的本地偏好回退到 `auto`。
- `auto` 响应系统变化，手动模式不响应系统变化。
- 首次绘制启动逻辑在样式加载前写入有效 `data-theme`。
- 两套主题使用完整语义变量，首页与详情面板不存在明显的硬编码浅色表面。

## 浏览器验收

使用内置浏览器优先，无法使用时回退 Safari。验证 1440×900、1024×768、901×844、
900×844 和 390×844：

- 文字层级与设计稿一致，搜索是视觉中心。
- 构建和背景信息明显弱于项目索引。
- `MESSAGE` / `SEND` / `OPEN` / 返回切换不引发宽度或高度跳动。
- 所有状态无横向滚动、重叠或小于 44px 的移动端交互目标。
- 定位授权胶囊仍处于最高视觉层，Dock 正确模糊且不可交互。
- `AUTO` 在系统明暗变化时实时切换；手动模式跨刷新保留并忽略系统变化。
- 首次以暗色偏好加载时不出现可见浅色闪烁。
- 首页、卡片、详情面板、Dock、授权胶囊和海报遮罩在两套主题下均无不可读文字或突兀白块。
