# Phase 15：四角色权限与内容发布治理

## 结果

HLC 的内容维护不再依赖浏览器保存的共享管理员密钥。Phase 15 建立了四种固定角色、
服务端会话、文章草稿审核发布流、账户治理和操作审计；Phase 14
的地图与七场所内容体验保持不变。

## 四种角色

| 角色               | 能力边界                                                                 |
| ------------------ | ------------------------------------------------------------------------ |
| 普通访客           | 读取已发布的公开内容                                                     |
| 社区居民（已注册） | 提交服务请求、参与互动，只查看本账户的服务记录                           |
| 社区工作者         | 维护内容和资源、保存草稿、提交审核、处理社区请求；不能发布内容或管理账户 |
| 管理员             | 审核发布与归档内容、管理账户/角色/状态、查看审计记录和系统配置           |

权限判断默认拒绝，并在服务端执行。前端隐藏按钮只负责表达界面能力，不作为安全边界。

## 内容状态流

```text
社区工作者保存草稿 → 提交审核 → 管理员发布 → 公开页面可见
                         ↘ 退回草稿
管理员可将已发布内容归档 → 公开页面不再返回该内容
```

- `save_article` 只写入 `content_workflow` 草稿，不直接覆盖公开内容。
- `submit_article` 只允许草稿作者或管理员提交审核。
- `publish_article` 和 `archive_article` 只允许管理员调用。
- 发布时才把审定版本原子写入既有 `intro` / `news` 等公开 KV 键。
- 账户、登录、草稿、审核和发布动作写入 `audit` 时间序列。

## 账户与会话

- 密码使用带随机盐的 PBKDF2-SHA-256 派生记录，数据库不保存明文密码。
- 登录成功后只下发 `HttpOnly`、`SameSite=Lax` 的不透明会话 Cookie；HTTPS 下增加
  `Secure`。
- 会话只保存散列后的令牌键，并由 Deno KV 自动过期。
- 普通访客可从“场所一览”打开账户入口，自助注册固定为社区居民角色；注册成功后立即建立
  登录会话。前端提交的角色字段不会提升权限，工作者和管理员仍只能由管理员创建。
- 自助注册校验账号、显示名和 10 至 256 位密码，并使用 KV
  原子写入阻止并发重复账号。
- `/login` 不再接受数据库清空、欠费或备份等隐藏命令。
- 管理员可在“账户与审计”中创建居民、社区工作者和管理员账号，启用或停用账号；
  当前管理员不能停用或降级自己。

社区账户入口位于“场所一览”底部。“场所一览”按钮与展开面板属于同一个导航状态组件：收起
时只显示按钮，展开后按钮从同一左下锚点过渡为场所列表；进入账户入口时，同一组件再切换为
登录、居民注册、加载、错误或居民账户状态，不再同时显示一个独立按钮，也不打开覆盖地图的
全屏页面。较长的注册表单只在组件内部滚动。用户可返回场所列表，关闭组件也会复位账户视图。
居民登录后继续在组件内查看本账户的服务记录；社区工作者和管理员只有认证成功后才进入内容
维护页。原有连续点击入口仍保留，作为维护人员的快捷入口，但不再绕过登录。

## 首个管理员

首次运行需要通过环境变量创建首个管理员，不提供代码内默认密码：

```bash
cd domains/hlc
HLC_ADMIN_USERNAME=admin \
HLC_ADMIN_PASSWORD='请替换为至少 10 位的强密码' \
deno run --no-config -A --unstable-kv index.js
```

已经完成旧部署迁移时，可以暂时使用 `ADMIN_KEY`
作为一次性引导密码来源；账号创建后应改用 `HLC_ADMIN_PASSWORD`
并移除旧变量。`HLC_KV_PATH` 可让本地测试使用独立 KV 文件，`PORT` 可覆盖默认的
`8000` 端口。

## 主要接口

| 接口                                             | 权限                       |
| ------------------------------------------------ | -------------------------- |
| `POST /register`                                 | 访客自助创建居民账户并登录 |
| `POST /login`、`POST /logout`、`GET /session`    | 账户会话                   |
| `GET/POST /accounts`、`GET /audit_list`          | 管理员                     |
| `GET /managed_content`、`POST /save_article`     | 社区工作者、管理员         |
| `POST /submit_article`                           | 草稿作者或管理员           |
| `POST /publish_article`、`POST /archive_article` | 管理员                     |
| `GET /my_requests`                               | 已登录用户，仅返回本人记录 |

## 验收基线

- 普通访客调用资源写接口返回 `401`。
- 访客注册后只能获得居民角色；重复账号返回 `409`，错误密码返回 `401`。
- 社区工作者能保存和提交自己的草稿，但发布返回 `403`。
- 管理员发布后，内容才进入公开 `article_list`。
- 管理员能查看账户列表和最近审计记录；社区工作者看不到账户治理入口和发布操作。
- 全部 HLC 模型测试通过，地图首页、七场所和 15 项服务不回归。
